## 2. Параметры варианта и геометрическая область

### Форма ввода:
- **Координата X:** Checkbox `{-4, -3, -2, -1, 0, 1, 2, 3, 4}` (одиночный выбор).
- **Координата Y:** Text `(-5 ... 3)` — строгое неравенство: **$-5 < Y < 3$** (круглые скобки: не включая границы!).
- **Радиус R:** Select `{'1', '2', '3', '4', '5'}`.
- **Метод передачи данных:** HTTP `POST`.
- **Хранение данных:** сессионный компонент `ResultsBean`.

### Геометрическая область попадания:
1. **1-я четверть ($x \ge 0, y \ge 0$):** Прямоугольник шириной $R$ и высотой $R/2$:
   $$0 \le x \le R \quad \text{и} \quad 0 \le y \le \frac{R}{2}$$
2. **2-я четверть ($x \le 0, y \ge 0$):** Прямоугольный треугольник с вершинами $(0, 0), (-R/2, 0), (0, R)$:
   $$-\frac{R}{2} \le x \le 0 \quad \text{и} \quad 0 \le y \le 2x + R$$
3. **3-я четверть ($x \le 0, y \le 0$):** Пусто (точки не попадают).
4. **4-я четверть ($x \ge 0, y \le 0$):** Четверть круга радиуса $R$:
   $$x \ge 0, \quad y \le 0 \quad \text{и} \quad x^2 + y^2 \le R^2$$

## 3. Интерактивный Canvas-график
- Отрисовка динамических осей и масштабируемых фигур по выбранному значению $R$.
- **Ограничение пунктиром допустимой зоны:** на Canvas нанесена пунктирная рамка границ $X \in [-4, 4]$ и $Y \in (-5, 3)$.
- **Примагничивание курсора (магнит):** при наведении мыши маркер прицела примагничивается к допустимой зоне с отображением проекций на оси и текущих координат.
- **Обработка кликов:** клик по Canvas вычисляет координаты и отправляет запрос на сервер. Если $R$ не выбран — выводится уведомление о невозможности определения координат.
- **Отображение точек:** все точки из сессионного бина отображаются на графике зеленым (попадание) и красным (промах).

## 4. Сборка и развертывание

### Сборка WAR-архива:
```bash
./build.sh
```
В результате в директории `target/` будет сформирован готовый архив `weblab3.war`.

### Развертывание на WildFly:
1. Скопируйте `target/weblab3.war` в директорию автодеплоя WildFly:
   ```bash
   cp target/weblab3.war $WILDFLY_HOME/standalone/deployments/
   ```
2. Запустите WildFly в standalone-режиме:
   ```bash
   $WILDFLY_HOME/bin/standalone.sh -b 0.0.0.0
   ```
3. Откройте в браузере:
   ```
   http://localhost:8080/weblab3/controller
   ```

## 5. Автоматическое развертывание на сервере Helios (`deploy-helios.sh`)

Скрипт `deploy-helios.sh` полностью автоматизирует процесс сборки и развертывания на сервере Helios в соответствии со всеми требованиями лабораторной работы:
- Запуск WildFly в **standalone-конфигурации**;
- Настройка портов в соответствии с переданным **portbase** (`-Djboss.socket.binding.port-offset=...`);
- Доступ к **HTTP listener открыт для всех IP** (`-b 0.0.0.0 -bmanagement 0.0.0.0`);
- Автоматическая установка WildFly в домашнюю директорию `~/wildfly` на Helios (если еще не установлен);
- Деплой `weblab3.war` в `~/wildfly/standalone/deployments/`;
- Генерация вспомогательных скриптов управления `~/wildfly/{start,stop,restart,status,logs}-wildfly.sh`.

### Использование:
```bash
./deploy-helios.sh [HELIOS_USER] [PORTBASE] [SSH_PORT]
```
По умолчанию:
- `HELIOS_USER` = `s465457`
- `PORTBASE` = `25000` (HTTP порт = 25000, Management порт = 26910, Offset = 16920)
- `SSH_PORT` = `2222`

Пример вызова:
```bash
./deploy-helios.sh s465457 25000 2222
```

### Управление на сервере Helios:
- **Запуск:** `~/wildfly/start-wildfly.sh`
- **Остановка:** `~/wildfly/stop-wildfly.sh`
- **Перезапуск:** `~/wildfly/restart-wildfly.sh`
- **Статус:** `~/wildfly/status-wildfly.sh`
- **Логи в реальном времени:** `~/wildfly/logs-wildfly.sh`

### Доступ к веб-приложению:
- Прямой доступ: `http://helios.cs.ifmo.ru:25000/weblab3/controller`
- Через SSH-туннель:
  ```bash
  ssh -p 2222 -L 25000:localhost:25000 s465457@helios.cs.ifmo.ru -N
  ```
  После чего открыть в браузере: `http://localhost:25000/weblab3/controller`
